🤖 Askly - AI QnA Bot

An AI-powered chatbot built using Python, Streamlit, LangChain, and Google Gemini API ✨

Askly can answer questions in a simple chat interface just like a mini AI assistant 💬

🚀 Features
    AI-powered QnA chatbot
    Google Gemini integration
    Interactive chat UI
    Built with Streamlit
    Secure API key handling using .env
    Chat session support
    
🛠️ Tech Stack
    Python
    Streamlit
    LangChain
    Google Gemini API
    dotenv

⚙️ Setup Guide (In Terminal)
    1️⃣ Open Project Folder
        cd apps
    2️⃣ Run the App
        streamlit run QnA_chatbot.py
